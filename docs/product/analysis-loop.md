# Цикл анализа локации

## Экран

Как у Циан: карта на весь вьюпорт, поиск, слои, карточка объекта, боковая панель выводов.

Пользователь может:

- найти населённый пункт и взять его границу;
- обвести произвольную область;
- позже сравнить 2–3 контура (не в первом срезе).

Подсветка на карте:

| Тип | Геометрия | Цвет (смысл, не финальный UI) |
|-----|-----------|-------------------------------|
| Продажа | точка или участок | один цвет |
| Аренда | точка | второй |
| Торги | участок, чаще полигон | третий |
| Существующая торговая точка | точка | нейтральный / по категории |
| Дороги | линии | класс дороги, не «тип сделки» |

Участок земли и объявление о помещении — разные объекты. Не рисовать фиктивные «области аренды», если источник дал только точку.

## Три слоя правды

ИИ получает не сырой интернет, а собранный пакет по области. В UI и в промпте каждый показатель имеет тип:

- **Факт** — есть источник и дата (население района по Росстату, категория дороги OSM, организация 2ГИС).
- **Оценка** — модель от бенчмарков (выручка формата ₽/м² × площадь × поправка на сезон и конкуренцию). Всегда вилка, не одна цифра.
- **Неизвестно** — нет данных на этом масштабе. Так и пишем. Запрещено заполнять дыру правдоподобным числом.

## 1. Предложение (что можно купить / снять / выиграть)

Источники-кандидаты, по приоритету легальности и устойчивости:

- торги: открытые площадки (torgi.gov.ru и муниципальные лоты на землю/имущество);
- кадастр / НСПД: границы участка, категория земель, ВРИ — критично для «купить землю»;
- объявления: **легальный API / партнёрский фид — можно и нужно**, когда будет доступ. Запрещён только скрытый скрейп сайта как основа слоя. Пока договора нет — ссылка, которую вставляет пользователь.

Карточка объекта: цена, площадь/сотки, тип сделки, ссылка на источник, дата.

## 2. Портрет жителей

Считать по самой мелкой географии, где цифра реально публикуется. Для Малино это часто **район / городской округ**, не посёлок. В UI писать масштаб явно: «Ступинский район, не Малино».

- население и динамика (рост / убыль);
- средняя зарплата;
- структура занятости, если есть в муниципальной статистике;
- отсюда качественный портрет и осторожный средний чек (оценка, не факт).

Отдельный обязательный признак для дачных мест: **сезонность**. Зимний постоянный спрос и летний дачный поток — разные бизнесы. Если сезонного ряда нет, ИИ обязан снизить уверенность, а не усреднить год.

## 3. Конкуренция физических точек

Из карт (2ГИС / организации Яндекса / OSM как запасной слой):

- сети и независимые точки по категориям (продукты, аптека, общепит, стройка, услуги);
- координаты, формат если известен, площадь если известна;
- плотность в контуре и в изохроне 5/10/15 минут на машине.

Выручку конкретной Пятёрочки не обещаем. Считаем **ёмкость категории**: население в зоне доступности × частота × средний чек по бенчмарку формата, минус оценка уже стоящих метров. Выход — вилка и список допущений.

Для земли под новую точку полезны ещё: вакантные коммерческие помещения, якоря (станция, выезд на магистраль, крупный продуктовый), разрывы в покрытии категории.

## 4. Трафик

Публичного поштучного потока по каждой улице обычно нет.

v1 — класс дороги и связность (OSM: магистраль, главная, местная) плюс положение относительно выездов и станции. Это уже отличает «несёт поток» от «тупика к дачам».

Коммерческие индексы пробок и пешеходный трафик — отдельный лицензируемый слой позже, не блокер первого среза.

## 5. Что ещё входит в пакет для ИИ

Без этого рекомендации по Малино будут красивыми и пустыми:

- категория земель и вид разрешённого использования;
- изохрона, не только нарисованный полигон (кто реально доезжает);
- вилка цен сотки/м² внутри области против района;
- ограничения, которые ломают бизнес: газ, электрическая мощность, вода, подъезды фур — как чеклист неизвестного, пока нет данных;
- юридический тип предложения: торги vs свободная продажа vs аренда.

## Рекомендация ИИ

Роль: консультант, который открывал офлайн-точки и умеет отказать.

Вход: пакет области (факты/оценки/неизвестные) + короткий бриф (бюджет, горизонт, ограничения по форматам).

Выход строго структурированный, 3–4 точки:

- где (привязка к объекту предложения или к разрыву покрытия, не «где-то в центре»);
- что открывать и почему этот формат, а не соседний;
- порядок вложений (вилка) и что в неё входит;
- окупаемость (вилка) и при каких допущениях она разваливается;
- главный риск;
- чего не хватает, чтобы сузить вилку.

Если данных мало, честный ответ — «район интересный, точку выбирать рано» плюс какие 2–3 факта добрать. Это успех, не отказ модели.

Модель не выбираем заранее как «самую умную». Один сильный вызов на синтез после дешёвой сборки фактов. Качество держим eval-набором кейсов (Малино и соседние типы мест: город, трасса, дача, спальник).
