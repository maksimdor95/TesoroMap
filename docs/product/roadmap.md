# Дорожная карта TesoroMap

Продуктовый трекер. Отмечай `- [x]`, когда пункт реально готов (можно показать другому человеку на кейсе Малино).

Эталон успеха всего пути: инвестор обводит Малино, видит участки и торги на одной карте, открывает карточку без вкладок Росреестра, получает досье с фактами/оценками/неизвестным и 3–4 честные точки от консультанта.

Связанные документы: [vision](vision.md) · [цикл анализа](analysis-loop.md) · [архитектура](../architecture/ARCHITECTURE.md)

---

## Как пользоваться

- Иди по фазам по порядку. Внутри фазы можно параллелить, если нет зависимости.
- «Готово» = проверка на Малино, а не «код написан».
- ИИ не начинай, пока не закрыт **P1** (стык номер → участок → лот).
- Спорные пункты помечены `?` — решать до старта фазы.

## P1 — Вертикальный срез Малино (карта без ИИ)

Цель: один экран закрывает микрокейс «кадастр → торги → снова карта».

### Разведка источников (руками, один участок)

- [ ] Найти 1–3 реальных участка около Малино с кадастровым номером
- [ ] Зафиксировать ответ НСПД: поля геометрии, площади, категории, ВРИ, стоимости
- [ ] Найти связанные или соседние лоты на ГИС Торги (Московская область)
- [ ] Зафиксировать, где в карточке лота лежит кадастровый номер
- [ ] Записать контракт полей в `docs/architecture/` или рядом с коннекторами (что нормализуем)

### Каркас приложения

- [ ] Инициализация репозитория приложения (web + api)
- [ ] PostgreSQL + PostGIS локально (docker-compose или аналог)
- [ ] Карта на весь экран, подложка, поиск места
- [ ] Рисование / выбор области (полигон)
- [ ] API: создать область, получить объекты в контуре
- [ ] Хранение области и версии запроса

### Коннектор НСПД

- [ ] Поиск / загрузка участков по контуру (с нарезкой большого полигона)
- [ ] Кэш сырого ответа + нормализованная таблица участков
- [ ] Отображение полигонов участков на карте
- [ ] Карточка участка: номер, площадь, категория, ВРИ, дата съёма
- [ ] Ошибка НСПД не роняет карту (пустой слой + статус)

### Коннектор ГИС Торги

- [ ] Периодический опрос опубликованных лотов региона (Московская область)
- [ ] Нормализация: цена, тип, статус, ссылка, кадастровые номера
- [ ] Стык лот → участок по кадастровому номеру
- [ ] Подсветка торгов на карте отдельным цветом
- [ ] Лоты без номера: список области, без фейковой геометрии
- [ ] Клик по лоту фокусирует участок и открывает объединённую карточку

### Приёмка P1

- [ ] Демо на Малино: обводка → участки видны → хотя бы один лот стыкуется или честно «лотов с номером в контуре нет»
- [ ] Время от обводки до первых полигонов приемлемо (зафиксировать целевое: например &lt; 30 с с кэшем / прогресс без кэша)
- [ ] Никакого ИИ в этом релизе не требуется

**Критерий выхода:** закрыт ручной маршрут без второй вкладки кадастровой карты.

## P2 — Права, ограничения, пригодность участка

Цель: по клику понять, имеет ли смысл смотреть участок дальше.

### Справочный ЕГРН

- [ ] Кнопка «права и обременения» на карточке участка / лота
- [ ] Запрос только по выбранному объекту (не массово на контур)
- [ ] Сохранение среза: вид права, обременения, дата запроса — **без ФИО**
- [ ] Статусы: проверено / не запрашивалось / источник недоступен
- [ ] Юридический дисклеймер в UI: справочно, не замена выписки

### Град / зоны (после базового участка)

- [ ] `?` Решение: ЗОУИТ / терзоны в P2 или перенос в P3
- [ ] Если да: слой ограничений на карточке с пометкой источника
- [ ] Явный флаг «ВРИ / зона может запретить формат» в досье-заготовке

### Приёмка P2

- [ ] На 2–3 участках Малино видны разные исходы: чисто / есть обременение / неизвестно
- [ ] Массовой выгрузки прав нет

## P3 — Портрет местности и дороги

Цель: панель области отвечает «кто здесь живёт и что несёт поток», без выдуманных цифр.

### Статистика

- [ ] Подключить Росстат / ЕМИСС (или зафиксированный ручной датасет v0 по Ступинскому району)
- [ ] Показатели: население, динамика, средняя ЗП; занятость — если есть
- [ ] В UI всегда масштаб: «Ступинский район, не Малино»
- [ ] Признак сезонности для дачных мест (хотя бы качественный: дача / смешанный / город)
- [ ] Средний чек только как **оценка** с допущениями или «неизвестно»

### Дороги

- [ ] Импорт OSM дорог региона в PostGIS
- [ ] Классификация: магистраль / основная / местная
- [ ] Слой на карте + влияние на карточку области («есть центральный выезд / тупиковая сеть»)
- [ ] `?` Изохроны 5/10/15 мин — в P3 или P4

### Приёмка P3

- [ ] Панель Малино не врёт масштабом статистики
- [ ] Сезонность видна до любого ИИ

---

## P4 — Конкуренция офлайн-точек

Цель: видеть, кто уже стоит в контуре, и где дыры покрытия.

### Организации

- [ ] Выбор провайдера (2ГИС / Яндекс) и статус лицензии
- [ ] Загрузка точек по контуру: продукты, аптека, общепит, стройка, услуги (словарь категорий)
- [ ] Слой на карте + плотность по категориям
- [ ] Площадь / формат — только если источник отдаёт; иначе неизвестно
- [ ] Запасной слой OSM amenities, если лицензия не готова (с пометкой качества)

### Ёмкость (оценка, не факт)

- [ ] Формула вилки ёмкости категории с явным списком допущений
- [ ] Запрет показывать «выручка этой Пятёрочки» как факт
- [ ] Разрывы покрытия на карте (heatmap / маркеры «пусто относительно нормы»)

### Приёмка P4

- [ ] На Малино видно: какие сети есть, каких категорий мало
- [ ] Любая денежная цифра помечена как оценка

---

## P5 — Досье и ИИ-консультант

Цель: 3–4 точки с вилками, рисками и отказом при нехватке данных.

### Сборщик досье

- [ ] Единый JSON/пакет области: предложение, жители, конкуренция, дороги, права
- [ ] Каждый показатель: факт | оценка | неизвестно + источник + дата
- [ ] Версионирование досье (какие срезы источников вошли)
- [ ] Панель досье читаема человеком без модели

### Бриф перед рекомендацией

- [ ] Форма: бюджет (или «не указан»), горизонт, запреты форматов
- [ ] Без бюджета окупаемость только как методология / отказ назвать срок
- [ ] Сохранение брифа вместе с досье

### Рекомендация

- [ ] Один вызов модели по схеме ответа (не свободный чат)
- [ ] 3–4 точки, привязка к участкам / лотам / разрывам
- [ ] Вилки вложений и окупаемости, главный риск, чего не хватает
- [ ] Режим «точку выбирать рано» считается успехом
- [ ] Трейс: вход досье, ответ, токены, latency

### Evals

- [ ] Набор 20–50 кейсов, старт с Малино и соседних типов (дача, трасса, город, спальник)
- [ ] Рубрика: сезонность, масштаб статистики, нет фейковой выручки, нет окупаемости без бюджета
- [ ] Команда прогона локально / в CI
- [ ] Гейт: регресс по smoke-кейсам блокирует выкат промпта

### Приёмка P5

- [ ] Слепое сравнение: эксперт смотрит досье + ответ на Малино — не противоречит здравому смыслу
- [ ] Eval smoke зелёный

## P7 — Продукт для людей (не только для себя)

Цель: можно отдать второму инвестору без сопровождения.

### UX

- [ ] Онбординг в 1 экран: обведи → смотри слои → запроси совет
- [ ] Сохранённые области / история
- [ ] Экспорт досье (PDF или ссылка)
- [ ] Мобильная читаемость панели (карта может остаться desktop-first)

### Надёжность и стоимость

- [ ] Бюджеты запросов к НСПД / торгам / модели
- [ ] Очереди и retry коннекторов
- [ ] Мониторинг: ошибки источников, latency карты, cost на рекомендацию
- [ ] Роутинг моделей (дешёвая сборка метаданных vs сильный синтез) — если нужно

### Доверие

- [ ] Дисклеймеры: не финансовый совет, справочные права ≠ выписка
- [ ] Всегда видны источники на карточке показателя
- [ ] `?` Заказ официальной выписки ЕГРН как отдельное действие

### Приёмка P7

- [ ] Человек без тебя проходит кейс Малино за одну сессию
- [ ] Лог сессии воспроизводим (область → досье → рекомендация)

## P8 — Масштаб и монетизация (после product-market сигнала)

Не начинать, пока P1–P5 не закрыты на реальных пользователях.

- [ ] Регионы сверх Московской области (очередь регионов торгов + OSM)
- [ ] Сравнение 2–3 контуров
- [ ] История состоявшихся торгов (свой архив или второй коннектор)
- [ ] Коммерческий слой трафика / пешеходов (лицензия)
- [ ] Тарифы: бесплатный контур / платное досье / платная рекомендация
- [ ] Команда / роли / мультипользовательские проекты
- [ ] Юридическая упаковка B2B (агентства, небольшие сети)

## Зависимости (кратко)

```text
P0 docs
  → P1 карта + НСПД + торги + стык по номеру
      → P2 права по клику
      → P3 жители + дороги
      → P4 конкуренция
          → P5 досье + ИИ + evals
              → P6 объявления
              → P7 продукт для людей
                  → P8 масштаб / деньги
```

Параллелить осторожно: P3 и P4 после стабильного P1; P2 можно чуть раньше P3/P4. P5 только после того, как досье собирается руками из слоёв.
