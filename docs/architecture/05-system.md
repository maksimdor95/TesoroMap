## В двух абзацах

TesoroMap закрывает маршрут инвестора «кадастровая карта → торги → ЕГРН → снова карта» на одном экране. Связка — **кадастровый номер**. ИИ не ищет факты сам: коннекторы кладут данные в PostGIS, сборщик делает досье (факт / оценка / неизвестно), модель только синтезирует 3–4 точки по схеме.

```
Карта → API области → PostGIS ← коннекторы (НСПД, Торги, ЕГРН, OSM, org, статистика)
                         ↓
                    досье → advise (LLM) → eval
```
