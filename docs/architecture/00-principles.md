# Principles

Sources folded into TesoroMap:

1. **AI Engineer / FDE practice** (consume models via API; harness + evals win)
2. **New SDLC with vibe coding → agentic engineering** (factory model; intent as interface)

## Non‑negotiables

1. **Harness > model** — advantage is context, tools, gates, evals, observability.
2. **Evals are the quality instrument** — no ship of AI behavior without a measurement path.
3. **Intent → verification → implementation** — specs/tests/evals before (or with) generation.
4. **Static vs dynamic context** — short always-on rules; skills/RAG on demand.
5. **Prototype ≠ production** — vibe for spikes; agentic for anything shared or user-facing.
6. **Empirical loop** — research → hypothesis → experiment → eval → keep/ablate.
7. **Human judgment stays** — architecture, security, release, business correctness.
8. **Cost is a feature** — token economy, caching, model routing are first-class.

## What we optimize for

| Optimize | Deprioritize (default) |
|----------|-------------------------|
| Measurable quality | Fine-tuning |
| Ownable harness | Framework zoos |
| Real user/task evals | Demo-only prompts |
| Observability & traces | Blind prompt churn |
| Simple composable patterns | Premature multi-agent graphs |
