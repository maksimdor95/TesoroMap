# Архитектура TesoroMap

Каноническая страница системы. Продуктовый intent — в [`../product/vision.md`](../product/vision.md), шаги сборки — в [`../product/roadmap.md`](../product/roadmap.md), цикл анализа на карте — в [`../product/analysis-loop.md`](../product/analysis-loop.md).

---

## 1. Зачем эта архитектура

Инвестор сегодня ходит по вкладкам: бесплатная кадастровая карта → гос. торги → сведения ЕГРН → снова карта. TesoroMap повторяет этот маршрут **внутри одного экрана**.

Связка трёх шагов — **кадастровый номер**.

| Без номера | Следствие |
|------------|-----------|
| Торги | Лот нельзя положить на участок |
| Карта | Нельзя запросить права |
| ИИ | Нельзя привязать совет к реальному объекту |

Модель **не ищет** в интернете и **не ходит** в Росреестр сама. Она читает досье, собранное детерминированным кодом. Так ответ воспроизводим и проверяем evals.

---

## 2. Принципы

1. **Карта — UI, досье — контракт, модель — синтез.**  
2. **Harness > model.** Качество = источники + нормализация + гейты + трейсы.  
3. **Факт / оценка / неизвестно.** Дыру нельзя заполнять правдоподобным числом.  
4. **Один коннектор — один источник.** Сырой JSON источника не протекает в UI и в промпт.  
5. **Кэш обязателен.** НСПД и торги без SLA; повторные удары по геопорталу запрещены политикой.  
6. **Права — по клику, не на весь контур.** Без ФИО.  
7. **Скрейп Циан/Авито не основа слоя.** Лицензия, фид или ссылка пользователя.  
8. **Сначала вертикальный срез без ИИ** (участки + торги), потом консультант.  
9. **Evals — гейт на промпт и схему ответа**, не демо «один раз красиво ответил».  
10. **Стоимость токенов и запросов к источникам — продуктовая метрика.**

Подробнее про agentic SDLC: [`00-principles.md`](00-principles.md), [`01-sdlc-agentic.md`](01-sdlc-agentic.md).

## 3. Контекстная диаграмма

```text
┌─────────────────────────────────────────────────────────────┐
│  Браузер: карта, слои, карточки, панель досье, бриф, ответ │
└────────────────────────────┬────────────────────────────────┘
                             │ HTTPS JSON / tiles
┌────────────────────────────▼────────────────────────────────┐
│  API TesoroMap                                              │
│  области · объекты в контуре · карточки · досье · advise   │
└──────┬───────────────┬───────────────┬──────────────────────┘
       │               │               │
       ▼               ▼               ▼
┌────────────┐  ┌────────────┐  ┌────────────────────────────┐
│  PostGIS   │  │  Очереди   │  │  LLM API (только advise)   │
│  нормы +   │  │  коннекто- │  │  схема ответа + трейс      │
│  сырой кэш │  │  ров       │  └────────────────────────────┘
└──────┬─────┘  └──────┬─────┘
       │               │
       │    ┌──────────┼──────────────────────────────┐
       │    ▼          ▼              ▼               ▼
       │  НСПД    ГИС Торги   справ. ЕГРН    OSM / org / stat
       │  (гео)   (лоты)      (по клику)     (местность)
       └──────────────────────────────────────────────────────
```

Граница доверия: всё, что уходит в модель, уже лежит в досье и может быть показано пользователю **без** модели.

## 5. Модель данных (логическая)

### 5.1. Ядро

| Сущность | Ключ | Поля (минимум) |
|----------|------|----------------|
| `Area` | `area_id` | geometry, name?, created_at, bbox |
| `Parcel` | `cadastral_number` | geometry, area_m2, category, permitted_use, cadastral_value?, source_fetched_at |
| `Lot` | `lot_id` | notice_number, status, deal_type (sale/lease/tender), price_min, url, cadastral_numbers[], region_code, fetched_at |
| `LotParcelLink` | `(lot_id, cadastral_number)` | match_confidence |
| `RightsSnapshot` | `(cadastral_number, fetched_at)` | right_type?, encumbrances[], raw_ref, **no PII** |
| `Organization` | `(provider, external_id)` | category, name, point, chain?, area_m2? |
| `RoadSegment` | `osm_id` | class (trunk/primary/local), geometry |
| `StatSlice` | `(geo_unit, indicator, period)` | value, unit, geo_label («Ступинский район») |
| `Dossier` | `dossier_id` | area_id, payload_json, sources_versions, created_at |
| `Brief` | `brief_id` | dossier_id, budget?, horizon?, exclusions[] |
| `Advice` | `advice_id` | dossier_id, brief_id, points[3..4], model, tokens, latency_ms |
| `Listing` (позже) | external_id | point, price, deal_type, user_url / feed_id |

### 5.2. Геоправила

- Участок и торги с номером → **полигон**.  
- Объявление аренды/продажи помещения без контура → **точка**.  
- Нельзя рисовать фиктивный полигон «аренды», если источник дал точку.  
- Лот без кадастрового номера → только в списке, без подсветки участка.

### 5.3. Сырой кэш

Рядом с нормализованными таблицами хранится `source_raw`:

- `source` (nspd | torgi | egrn_ref | …)
- `request_key`
- `payload` (jsonb)
- `fetched_at`
- `ttl_hint`

Нужен для отладки смены схемы источника и чтобы не бить API повторно.

## 6. Коннекторы

Общий контракт коннектора:

```text
fetch(request) → normalize → upsert normals → store raw → emit metrics
```

Ошибки источника: retry с backoff, circuit breaker, статус слоя в API (`ok | degraded | empty`).

### 6.1. НСПД (кадастровая карта)

- **Зачем:** границы и атрибуты участка.  
- **Где:** [nspd.gov.ru](https://nspd.gov.ru) (публичная кадастровая карта).  
- **Операции:** поиск по номеру; пересечение контура (крупный контур — нарезка тайлами/частями).  
- **Риски:** нет SLA, лимиты площади, смена API.  
- **Политика:** кэш, дата съёма на карточке, карта живёт без свежего ответа.

### 6.2. ГИС Торги

- **Зачем:** лоты продажи/аренды/торгов с ценой и статусом.  
- **Где:** публичный JSON сайта [torgi.gov.ru](https://torgi.gov.ru) (`lotcards/search`, карточка лота).  
- **Операции:** опрос региона по расписанию (для Малино — Московская область); вебхуков нет.  
- **Стык:** извлечь кадастровые номера → `LotParcelLink` → геометрия из `Parcel`.  
- **Второй коннектор (опционально):** платный агрегатор истории аукционов — не ядро.

### 6.3. Справочный ЕГРН

- **Зачем:** вид права и обременения до решения «копать дальше».  
- **Когда:** только по клику / короткому списку.  
- **Не делать:** массовый обход контура; хранение ФИО; подмена официальной выписки.  
- **Официальная выписка:** отдельный пользовательский сценарий позже (платно, асинхронно).

### 6.4. Местность

| Источник | Данные | Режим |
|----------|--------|--------|
| OSM | дороги, иногда amenities | периодический импорт региона |
| 2ГИС / Яндекс Organizations | точки бизнеса | по области + кэш; нужна лицензия |
| Росстат / ЕМИСС | население, ЗП, занятость | редкое обновление; гранулярность района |
| Valhalla / аналог | изохроны | по запросу области |
| Пользователь / фид | объявления | P6 |

Чего **нет** в коннекторах и не обещаем: точная выручка конкретной точки; поштучный поток по каждой улице без коммерческой лицензии.

## 7. Потоки

### 7.1. Микрокейс (P1–P2)

```text
1. Пользователь ищет «Малино» или рисует контур
2. API создаёт Area
3. Читает из PostGIS Parcel ∩ Area, Lot связанные по номеру
4. Если Parcel пусто → job НСПД по контуру → upsert → push/poll обновления слоя
5. Лоты региона уже в базе с опроса → фильтр по номерам в Area
6. Клик Lot → focus Parcel + объединённая карточка
7. «Права» → RightsSnapshot → карточка
```

### 7.2. Досье и совет (P5)

```text
1. Сборщик читает слои Area → Dossier (факт/оценка/неизвестно)
2. Пользователь заполняет Brief (бюджет опционален)
3. Advise: prompt = Dossier + Brief + system schema
4. Валидация JSON ответа
5. Сохранение Advice + trace
6. Eval offline / CI на регрессию
```

Запрещённый поток: agent tool-call «сходи на torgi и реши сам» в обход Dossier.

## 8. API (черновик контракта)

Префикс условный `/api/v1`.

| Метод | Путь | Назначение |
|-------|------|------------|
| `POST` | `/areas` | Создать область (GeoJSON polygon) |
| `GET` | `/areas/{id}` | Метаданные + статусы слоёв |
| `GET` | `/areas/{id}/parcels` | Участки в контуре (geojson features) |
| `GET` | `/areas/{id}/lots` | Лоты в контуре / состыкованные |
| `GET` | `/parcels/{cadastral_number}` | Карточка участка |
| `POST` | `/parcels/{cadastral_number}/rights` | Запросить справочные права |
| `GET` | `/areas/{id}/organizations` | Точки конкуренции |
| `GET` | `/areas/{id}/stats` | Портрет с geo_label |
| `POST` | `/areas/{id}/dossier` | Собрать / обновить досье |
| `GET` | `/dossiers/{id}` | Пакет для UI |
| `POST` | `/dossiers/{id}/advise` | Brief + рекомендация |
| `GET` | `/advice/{id}` | Сохранённый ответ |

Ошибки слоёв — в теле области (`layers.nspd = degraded`), не обязательно 5xx на весь экран.

## 9. Клиент карты

### Обязательный UX

- Карта на весь вьюпорт (ориентир — Циан).  
- Поиск населённого пункта.  
- Draw polygon / выбрать границу.  
- Переключатели слоёв: участки, торги, организации, дороги.  
- Легенда цветов по типу сделки.  
- Карточка объекта + боковая панель досье.  
- Бриф появляется только перед «Получить рекомендации».

### Состояния слоя

`idle → loading → ready | empty | degraded`

Пользователь всегда видит, **чего не хватает**, а не пустую карту без объяснения.

## 10. Досье и ИИ-harness

### 10.1. Форма показателя

```json
{
  "key": "population",
  "kind": "fact",
  "value": 120000,
  "unit": "people",
  "geo_label": "Ступинский район",
  "as_of": "2024-01-01",
  "source": "rosstat",
  "notes": null
}
```

`kind`: `fact` | `estimate` | `unknown`.

### 10.2. Выход advise (схема)

Каждая из 3–4 точек:

- `location_ref` — cadastral_number и/или lot_id и/или «разрыв категории X»
- `concept` — что открывать
- `why` — опора на поля досье
- `capex_range` — вилка
- `payback_range` — вилка или `null` + причина (нет бюджета)
- `main_risk`
- `missing_facts[]`
- `confidence` — низкая, если сезонность/ВРИ неизвестны

Глобальный исход: `recommend` | `too_early`.

### 10.3. Evals

Датасеты: `agent/evals/datasets/`.  
Рубрики: `agent/evals/rubrics/`.  
Кейс Малино обязан провалить ответ, который:

- игнорирует сезонность дачи;
- выдаёт выручку конкретной сети как факт;
- называет срок окупаемости без бюджета;
- путает масштаб «Малино» и «Ступинский район».

Подробнее: [`03-evals.md`](03-evals.md), [`02-ai-harness.md`](02-ai-harness.md).

## 11. Стек v0 (зафиксировано)

Выбрано под навыки этого компьютера (Kabi: FastAPI + Postgres; hotRoad: Vite + React) и под PostGIS.

| Слой | Выбор | Зачем |
|------|--------|--------|
| Frontend | **Vite + React + TypeScript + MapLibre** | Быстрый UI, карта со своими слоями, токены из `docs/design/` |
| Backend | **Python FastAPI** | Коннекторы НСПД/торги, httpx, гео-скрипты — как в Kabi |
| DB | **PostgreSQL + PostGIS** | Контуры и участки. Локально docker; облако — Neon (тот же Postgres) |
| Jobs | APScheduler / фоновые задачи в FastAPI-процессе на старте | Опрос торгов, догрузка НСПД; очередь усложним позже |
| Auth | **не в P1** → WorkOS AuthKit в P7 | Сейчас мешает вертикальному срезу |
| LLM | **не в P1** → прямой API провайдера в P5; Neon AI Gateway опционально | Один вызов advise по досье |
| Deploy | позже | Сначала Малино локально |

Не тащить multi-agent framework и не плодить второй backend на Node без нужды.

## 12. Безопасность, право, этика данных

- Не хранить ФИО собственников.  
- Дисклеймер: не инвестиционная рекомендация; справочные права ≠ выписка ЕГРН.  
- Секреты API только в env; не в промпты и не в трейсы.  
- Трейсы advise редактировать от PII, если пользователь вставит личное в бриф.  
- Соблюдать ToS источников; лицензии org-API до продакшен-нагрузки.  
- Prompt injection: пользовательский бриф — данные, не инструкции; схема ответа валидируется кодом.

## 13. Наблюдаемость и стоимость

Метрики минимум:

- latency `POST /areas` → первые features;
- доля лотов состыкованных по номеру;
- error rate коннекторов;
- cache hit НСПД;
- cost и latency `advise`;
- eval score smoke на релизе промпта.

Алерты: падение стыка лот↔участок, рост 5xx НСПД, скачок стоимости advise.

## 14. Отказоустойчивость

| Сбой | Поведение |
|------|-----------|
| НСПД недоступен | Показать кэш; статус degraded; торги и статистика живут |
| Торги не обновились | Показать last sync; не блокировать участки |
| ЕГРН по клику упал | Карточка участка без прав + «повторить» |
| LLM упал / схема невалидна | Досье остаётся; advise retry; без «полуответа» |
| Пользователь нарисовал огромный контур | Нарезка + прогресс; лимит площади с понятной ошибкой |
